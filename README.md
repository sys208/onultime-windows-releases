# 오늘시간표 Windows

학생용 오늘시간표 Windows 앱의 설치·업데이트 파일 배포 저장소입니다. 소스코드는 포함하지 않습니다.

[최신 설치파일](https://github.com/sys208/onultime-windows-releases/releases/latest)

- Windows x64용 Setup.exe로 설치합니다.
- 앱의 설정 → 앱 업데이트 확인에서 새 버전을 확인할 수 있습니다.
- 업데이트 정보의 전자서명과 파일 무결성을 검증합니다.
- 현재 최초 설치 EXE에는 Windows Authenticode 게시자 인증서가 적용되지 않았습니다. 업데이트 검증용 전자서명과는 별개입니다.
